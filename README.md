# DS-BOT — музыка, видео и фильмы в Discord

## Что умеет

**Музыка** (YouTube, YouTube Music, SoundCloud, Bandcamp, Twitch, прямые ссылки, свои файлы)
- `/play` — ссылка, плейлист или просто название песни
- `/playnext` — поставить следующим · `/playfile` — включить свой mp3/wav/mp4
- `/search` — поиск с выбором из 5 вариантов
- Панель «Сейчас играет» с кнопками: ⏸️ ⏭️ ⏹️ 🔁 🔀 🔉 🔊 📜
- `/pause` `/resume` `/skip` `/stop` `/join` `/leave` `/nowplaying`

**Очередь**
- `/queue` (по страницам), `/remove`, `/move`, `/skipto`, `/clear`, `/shuffle`
- `/loop` — выкл / повтор трека / повтор очереди
- `/volume` 1–150 %, `/seek 1:30` — перемотка
- Сам выходит из канала, если все ушли или музыки нет 5 минут
- `/filter` — эффекты: bass boost, nightcore, slowed + reverb, vaporwave, 8D, быстрее/медленнее, караоке
- `/normalize` — выравнивание громкости (включено по умолчанию)
- Название трека пишется в статус голосового канала

**Веб-панель** — `/panel`
- Управление из браузера или с телефона: что играет, перемотка, громкость, эффекты,
  поиск, очередь с перетаскиванием
- Для телефона укажи в `.env` `PUBLIC_URL=http://IP-компьютера:8080` (IP — из команды `ipconfig`)

**Видео**
- `/watch` — **Watch Together**: YouTube прямо в голосовом канале, у всех синхронно
- `/video` — найти видео и скинуть в чат (с кнопкой «Смотреть вместе»)

**Фильмы с компьютера** (необязательно)
- `/films` — список фильмов из твоей папки, `/film` — ссылка на веб-плеер с перемоткой

> ⚠️ Боты Discord технически **не могут** показывать видео в голосовом канале
> (демонстрация экрана есть только у людей). Поэтому фильмы смотрятся так: один
> открывает ссылку от `/film` в браузере и включает **Демонстрацию экрана** со звуком.

## Установка (Windows)

### 1. Создай бота
1. https://discord.com/developers/applications → **New Application**
2. Вкладка **Bot** → **Reset Token** → скопируй токен
3. Вкладка **General Information** → скопируй **Application ID**
4. Пригласи бота на сервер по ссылке (вставь свой ID):
   ```
   https://discord.com/oauth2/authorize?client_id=ТВОЙ_APPLICATION_ID&scope=bot+applications.commands&permissions=282024735755265
   ```
   (права: видеть каналы, писать, ссылки, подключаться, говорить, создавать приглашения, активности, ставить статус голосового канала)

### 2. Установи
1. Python 3.11+ с https://python.org (галочка **Add python.exe to PATH**)
2. Запусти **install.bat** — поставит библиотеки, FFmpeg и Deno
3. Открой файл **.env** блокнотом, вставь `DISCORD_TOKEN=...` и `GUILD_ID=...` (ID сервера)

### 3. Запусти
**start.bat** — при каждом запуске обновляет yt-dlp (YouTube часто всё ломает) и
перезапускает бота, если он упал.

## Фильмы
В `.env`:
```
FILMS_DIR=E:\Films
WEB_PORT=8080
PUBLIC_URL=http://192.168.1.50:8080
WEB_KEY=придумай_пароль
```
- Для себя и домашней сети — укажи IP компьютера (команда `ipconfig`).
- Чтобы друзья открыли из интернета — проброс порта 8080 на роутере
  или туннель (Cloudflare Tunnel / ngrok), и тогда **обязательно** задай `WEB_KEY`.
- Лучший формат — **mp4 (H.264 + AAC)**. mkv/avi браузер может не открыть.

## Если что-то не работает
| Проблема | Решение |
|---|---|
| Команды не появились | Укажи `GUILD_ID` в `.env`, перезапусти |
| Бот зашёл, но молчит | Нет FFmpeg → `install.bat` или `FFMPEG_PATH` в `.env` |
| Ошибка 4017 при подключении | Обнови: `.venv\Scripts\python -m pip install -U "discord.py[voice]" davey` |
| YouTube: «Sign in to confirm you're not a bot» | Экспортируй cookies YouTube в `cookies.txt`, пропиши `COOKIES_FILE=cookies.txt` |
| YouTube вообще перестал играть | Перезапусти `start.bat` (обновит yt-dlp), проверь что Deno установлен |
| Статус канала не меняется | Перепригласи бота по новой ссылке выше (нужно право «Устанавливать статус голосового канала») |
| Панель не открывается с телефона | `PUBLIC_URL` с IP компьютера + разрешить Python в брандмауэре Windows |
| `/watch` не создаёт активность | У бота нет права «Создавать приглашения» в этом канале |

Spotify-ссылки не поддерживаются (там защита DRM) — ищи песню по названию.
